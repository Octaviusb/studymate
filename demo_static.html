⚙️ Configuración Rápida

Opción 1: XAMPP (Recomendado)
1. Descargar XAMPP de apachefriends.org
2. Copiar proyecto a C:\xampp\htdocs\studymate
3. Iniciar Apache y MySQL
4. Ir a http://localhost/studymate/quick_populate.php
Opción 2: InfinityFree
1. Subir archivos a tu hosting
2. Configurar base de datos
3. Ejecutar setup desde tu dominio
